## About

**Masque: Muq** is an add-on for [World of Warcraft](https://worldofwarcraft.com "World of Warcraft") that adds a custom skin for [Masque].

## Requirements

This add-on requires [Masque].

## Installation

Install the package through your preferred add-on manager or extract the archive to your add-ons directory.
